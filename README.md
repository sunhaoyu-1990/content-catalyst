## 📖 项目简介

这是一个基于 Claude AI 的内容创作助手，支持为多个平台（知乎、领英、小红书、X/Twitter）自动生成高质量内容。

**核心特性**：
- ✅ 多平台支持（知乎、领英、小红书、X）
- ✅ 智能资料收集（4轮搜索策略）
- ✅ 选题评分筛选（10分评分系统）
- ✅ 一键内容生成
- ✅ 自动质量审查
- ✅ 自动图片标记
- ✅ 双模式（极简/完整）

## 📂 两个目录的区别

| 特性 | workspace/ | talk_with_ai/ |
|------|-----------|---------------|
| **用途** | 存放创作产出 | 存放对话记录 |
| **像什么** | 作品档案库 | 聊天记录本 |
| **内容举例** | 文章草稿、最终内容、发布状态 | 对话摘要、关键洞察、行动项 |
| **结构** | 4层：主题→版本→阶段→平台 | 2层：主题→版本 |

**简单记忆**：
- `workspace/` = 你的**作品**（对外发布的内容）
- `talk_with_ai/` = 我们的**对话**（交流的想法和计划）

## 🎯 模式选择

### 极简模式（推荐新手）

**适用场景**：
- 快速创作一篇内容
- 不需要版本管理
- 不需要跨平台复用

**使用方法**：
```bash
# 直接使用 create 命令
/xiaohongshu-create "你的选题"
```

**自动化流程**：
```
创作 → 自动审查 → 自动标记 → 完成
```

### 完整模式（推荐高级用户）

**适用场景**：
- 系统化管理多个内容
- 需要版本控制和历史追溯
- 需要跨平台内容复用

**使用方法**：

```bash
# 1. 创建目录结构
mkdir -p workspace/ai-tools/2026-01-30/{00_collect,01_filter,02_create,03_publish}/{zhihu,xiaohongshu}

# 2. 收集资料
/zhihu-collect "AI写作工具"

# 3. 筛选选题
/zhihu-filter

# 4. 创作内容
/zhihu-create "AI写作工具深度评测"

# 5. 自动触发审查和标记（规则自动执行）
#    - 质量审查
#    - 图片标记

# 6. 发布准备
/zhihu-publish

# 7. 更新索引
# 手动编辑 workspace/index.md
```

**目录结构**：
```
workspace/
├── index.md                # 主索引
└── {topic}/
    └── {version}/          # 2026-01-30, v2, v3...
        ├── 00_collect/     # 收集阶段
        ├── 01_filter/      # 筛选阶段
        ├── 02_create/      # 创作阶段
        ├── 03_publish/     # 发布阶段
        └── task.md         # 任务导航
```

**完整模式优势**：
- ✅ 4阶段流程规范化
- ✅ 版本管理和历史追溯
- ✅ 跨平台内容复用
- ✅ 自动化规则触发

## ⚙️ 自动化功能

### 规则驱动架构（v1.5新增）

系统内置3个自动化规则，无需手动触发：

| 规则 | 功能 | 触发时机 |
|------|------|---------|
| **完整模式控制** | 引导4阶段流程执行 | 检测到完整模式目录结构 |
| **质量审查** | 自动审查6个维度 | 文章初稿完成（>1000字） |
| **图片标记** | 自动添加图片标记 | 审查通过后 |

### 质量审查维度

创作完成后自动检查：
- ✅ 事实准确性
- ✅ 逻辑一致性
- ✅ 语言质量
- ✅ 平台适配
- ✅ 结构完整性
- ✅ 原创性

## 📊 平台特色

### 知乎 - 专业深度

**特点**：专业严肃、深度分析
**评分权重**：专业性(4) + 可信度(3) + 热度(2) + 相关性(1)
**内容类型**：技术文章、专业回答、深度分析

### 领英 - 商业视角

**特点**：职业化、商业价值
**评分权重**：商业价值(4) + 专业性(3) + 热度(2) + 相关性(1)
**内容类型**：行业洞察、管理经验、ROI分析

### 小红书 - 种草分享

**特点**：亲和力强、种草风格
**评分权重**：热度(5) + 种草价值(3) + 争议性(2) + 相关性(0)
**内容类型**：种草笔记、测评分享、使用心得

### X/Twitter - 简洁有力

**特点**：简洁有力、高传播
**评分权重**：影响力(4) + 相关性(3) + 时效性(2) + 传播度(1)
**内容类型**：短推文、长线程、回复互动

## ❓ 常见问题

### Q1: 如何开始第一次创作？

**A**: 最简单的方式：
```bash
/xiaohongshu-create "你想写的主题"
```
系统会自动完成创作、审查、图片标记。

### Q2: 创作内容保存在哪里？

**A**:
- 极简模式：`workspace/{topic}/content.md`
- 完整模式：`workspace/{topic}/{version}/02_create/{platform}/article.md`

### Q3: 如何查看历史创作？

**A**: 查看 `workspace/index.md` 主索引文件。

### Q4: 创作失败怎么办？

**A**:
1. 检查主题是否明确
2. 尝试提供更详细的说明
3. 查看错误日志了解原因

### Q5: 如何自定义用户画像？

**A**: 在 create 命令中添加 `--profile` 参数，或在对话中描述你的用户画像。

### Q6: 支持哪些平台？

**A**: 目前支持知乎、领英、小红书、X/Twitter。持续扩展中。

### Q7: 如何确保内容质量？

**A**:
- 系统自动触发质量审查（6个维度）
- 建议人工审核后再发布
- 可以使用 content-reviewer 技能进行深度审查

### Q8: 图片如何生成？

**A**:
- 系统自动添加图片标记（包含 Prompt）
- 将 Prompt 复制到 AI 绘图工具（如 Midjourney）
- 生成的图片插入文章即可
