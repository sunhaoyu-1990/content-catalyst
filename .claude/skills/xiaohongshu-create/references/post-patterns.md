# 小红书内容类型模式

## 种草笔记

**风格特点**：图文并茂、突出产品优势、种草力强

**使用场景**：
- 产品推荐
- 好物分享
- 体验推荐

**结构模板**：
```
📌 吸引眼球的标题（使用 emoji，20字内）

## 开场
- 引起共鸣的开场白
- 痛点/需求描述

## 产品介绍
### 产品/服务亮点 1
- 详细说明 + 图片说明
- 使用体验/效果

### 产品/服务亮点 2
...

## 个人体验
- 真实使用感受
- 前后对比（如有）

## 使用建议/推荐场景
- 适合人群
- 使用场景
- 注意事项

## 优惠信息（如有）
- 价格/购买渠道
- 优惠活动

## 结尾
- 互动引导（收藏/点赞/评论）
- 行动号召
```

**示例**：
```
📚 学生党必看！这些AI学习工具让我的效率提升了300%！

姐妹们！今天必须给你们种草我最近发现的宝藏AI学习工具...

[详细内容...]

💡 记得点赞收藏哦～
```

## 测评分享

**风格特点**：真实体验、客观评价、多角度分析

**使用场景**：
- 多产品对比
- 使用心得
- 真实测评

**结构模板**：
```
🔍 吸引眼球的标题（包含测评对象）

## 测评背景
- 测评对象
- 使用时长
- 测评目的

## 产品对比
| 产品 | 价格 | 效果 | 推荐度 |
|------|------|------|--------|
| 产品1 | ... | ... | ⭐⭐⭐⭐⭐ |
| 产品2 | ... | ... | ⭐⭐⭐⭐ |

## 详细体验
### 优点
- 优点1 + 具体例子
- 优点2 + 具体例子

### 缺点
- 缺点1 + 具体例子
- 缺点2 + 具体例子

### 使用感受
- 实际使用场景
- 满意度评价

## 总结推荐
- 综合评分
- 适用人群
- 购买建议
```

## 生活方式

**风格特点**：生活场景、个人品味、真实接地气

**使用场景**：
- 日常记录
- 生活分享
- 个人成长

**结构模板**：
```
🌸 吸引眼球的标题（生活化表达）

## 场景描述
- 时间、地点、事件
- 氛围营造

## 个人体验
- 我的感受/体会
- 前后变化

## 分享要点
- 要点1 + 图片/配图
- 要点2 + 图片/配图
- 要点3 + 图片/配图

## 互动引导
- 引起共鸣的问题
- 邀请分享经验

## 结语
- 感悟/总结
- 未来规划
```

## 美妆教程

**风格特点**：步骤详细、易于跟随、图文并茂

**使用场景**：
- 技能教学
- 步骤演示
- 技巧分享

**结构模板**：
```
💄 吸引眼球的标题（突出教程主题）

## 教程目标
- 学会后能达到的效果
- 适用人群/场景

## 准备工作
### 需要的工具/产品
- 工具1: 用途 + 图示
- 工具2: 用途 + 图示

### 前期准备
- 准备步骤1
- 准备步骤2

## 详细步骤
### Step 1: {步骤名称}
- 具体操作说明
- 注意事项
- 配图/演示

### Step 2: {步骤名称}
...

## 常见问题
- 问题1: 解决方案
- 问题2: 解决方案

## 效果展示
- 最终效果
- 前后对比

## 小贴士
- 注意事项
- 进阶技巧
```

## 穿搭灵感

**使用场景**：
- 穿搭展示
- 搭配技巧
- 风格定位

```
👗 吸引眼球的标题（风格/场景描述）

- 风格: {风格名称}
- 场景: {通勤/约会/职场/日常}
- 季节: {春夏秋冬}

## 单品展示
### 单品1
- 品牌/款式
- 购买渠道/价格
- 搭配思路

### 单品2
...

## 搭配方案
### 方案 1: {场景描述}
- 穿搭效果
- 单品清单
- 适合体型/场合

### 方案 2: ...

## 搭配技巧
- 技巧1: 详细说明
- 技巧2: 详细说明

## 配饰建议
- 鞋包搭配
- 配饰点缀
- 色彩呼应
```
