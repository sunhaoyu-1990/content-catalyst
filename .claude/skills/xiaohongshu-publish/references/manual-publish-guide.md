# 小红书手动发布指南

## 发布方式

### 方式 1: 使用创作者平台（推荐）

#### 步骤 1: 登录创作者平台

1. 访问 [小红书创作者平台](https://creator.xiaohongshu.com)
2. 使用小红书账号登录
3. 进入「发布笔记」页面

#### 步骤 2: 选择内容类型

**图文笔记**:
- 点击「图文」标签
- 上传 1-9 张图片（推荐 5-9 张）
- 支持拖拽上传

**视频笔记**:
- 点击「视频」标签
- 上传视频文件（15 秒 - 5 分钟）
- 选择封面图（可自定义）

#### 步骤 3: 填写内容

**标题** (必填，≤ 20 字):
```
📚 学生党必看！这些AI学习工具让我的效率提升了300%！
```

**正文** (≤ 1000 字):
```
姐妹们！今天必须给你们种草我最近发现的宝藏AI学习工具...

[正文内容...]

💡 记得点赞收藏哦～
```

**话题标签** (最多 10 个):
```
#AI工具 #学习效率 #学生党 #种草推荐 #好物分享
```

#### 步骤 4: 补充信息（可选）

- **添加地点**: 点击「添加地点」选择位置
- **@好友**: 在正文中输入 @ 可以提醒其他用户
- **选择合集**: 添加到已有合集或创建新合集

#### 步骤 5: 预览和发布

1. 点击「预览」按钮查看效果
2. 检查内容和排版
3. 确认无误后点击「发布」
4. 等待发布成功提示

---

### 方式 2: 使用剪贴板工具

当 Playwright 自动化不可用时，使用剪贴板工具手动复制内容。

#### 步骤 1: 使用剪贴板工具

在项目目录运行：

```bash
cd .claude/skills/xiaohongshu-publish/scripts

# Windows
python copy_to_clipboard.py text "你的内容"

# macOS/Linux
python3 copy_to_clipboard.py text "你的内容"
```

#### 步骤 2: 粘贴到创作者平台

1. 访问 https://creator.xiaohongshu.com/publish/publish
2. 将剪贴板内容粘贴到对应位置：
   - 标题 → 标题输入框
   - 正文 → 正文输入框
   - 话题标签 → 话题输入框
3. 上传图片/视频
4. 点击「发布」

---

### 方式 3: 使用 APP 发布

#### 步骤 1: 打开小红书 APP

1. 打开小红书移动应用
2. 点击右上角「+」号

#### 步骤 2: 选择发布类型

- **图文**: 选择「相册」上传图片
- **视频**: 选择「拍摄」或「相册」上传视频

#### 步骤 3: 编辑内容

1. 添加标题和正文
2. 添加话题标签（点击「#」）
3. 添加地点（可选）
4. @好友（可选）

#### 步骤 4: 发布

1. 点击「发布」按钮
2. 等待发布成功

## 内容规范

### 标题规范

- 长度: ≤ 20 字
- 风格: 吸引眼球，使用 emoji
- SEO: 包含关键词

**示例**:
```
✓ 好标题: 📚 学生党必看！这些AI学习工具让效率提升300%！
✗ 差标题: 关于AI学习工具的介绍
```

### 正文规范

- 长度: 100-1000 字（推荐 500-800 字）
- 结构: 分段清晰，重点突出
- 表情: 适度使用 emoji
- 互动: 结尾引导点赞收藏

**示例**:
```markdown
姐妹们！今天必须给你们种草我最近发现的宝藏AI学习工具

## 产品介绍
✨ 工具1: XXX
- 功能：XXX
- 使用体验：XXX

## 个人体验
我用了这个工具一个月，效率提升了300%...

💡 记得点赞收藏哦～
```

### 话题标签规范

- 数量: 最多 10 个（推荐 5-7 个）
- 组合: 热门话题 + 垂直领域 + 长尾标签

**标签组合示例**:
```
#AI工具 (热门)
#学习效率 (热门)
#学生党 (垂直)
#种草推荐 (垂直)
#好物分享 (热门)
#AI学习 (长尾)
```

### 图片规范

- 数量: 1-9 张（推荐 5-9 张）
- 比例: 3:4 (竖图) 或 1:1 (方图)
- 格式: JPG, PNG
- 大小: 单张 ≤ 20MB
- 质量: 高清，不模糊

### 视频规范

- 时长: 15 秒 - 5 分钟（推荐 30 秒 - 3 分钟）
- 格式: MP4, MOV
- 大小: ≤ 500MB
- 分辨率: 720p 及以上
- 封面: 选择吸引人的封面图

## 发布后检查

### 检查清单

发布后 24 小时内检查：

- [ ] 内容正常显示
- [ ] 图片/视频加载正常
- [ ] 话题标签生效
- [ ] 数据统计正常（浏览、点赞、收藏）
- [ ] 评论回复及时

### 数据优化

根据发布后数据优化：

- **浏览量低**: 优化标题和封面
- **互动率低**: 优化结尾引导
- **收藏量低**: 增加实用价值
- **评论量少**: 增加话题讨论点

## 常见问题

### Q1: 发布失败怎么办？

**A**: 检查以下几点：
1. 标题是否超过 20 字
2. 正文是否超过 1000 字
3. 话题标签是否超过 10 个
4. 图片/视频格式是否正确
5. 网络连接是否正常

### Q2: 如何提高曝光？

**A**: 优化以下几点：
1. 使用热门话题标签
2. 发布时间（推荐 9-11 点，18-22 点）
3. 封面图质量
4. 标题吸引人
5. 互动引导

### Q3: 草稿箱在哪里？

**A**:
- 创作者平台: https://creator.xiaohongshu.com/publish/draft
- APP: 侧边栏 → 草稿箱

### Q4: 如何编辑已发布内容？

**A**:
1. 找到已发布的笔记
2. 点击「...」更多选项
3. 选择「编辑」
4. 修改后保存

## 附录：快捷键

### 创作者平台

| 快捷键 | 功能 |
|--------|------|
| Ctrl + Enter | 发布 |
| Ctrl + S | 保存草稿 |

| 快捷键 | 功能 |

| Ctrl + I | 斜体（部分支持） |
