# 知乎手动发布指引

## 发布步骤

### 1. 登录知乎
- 访问: https://www.zhihu.com
- 点击右上角"登录"
- 使用手机号/邮箱或第三方账号登录
- 确保登录成功（能看到个人信息）

---

### 2. 发布专业回答

**方式 A：回答具体问题**

1. 找到要回答的问题
   - 在知乎搜索问题关键词
   - 或直接访问问题链接

2. 点击"写回答"按钮
   - 在问题页面右侧或下方找到"写回答"按钮
   - 点击进入编辑器

3. 粘贴标题（可选）
   - 如果是专栏文章形式，可以添加标题
   - 一般回答不需要标题

4. 粘贴正文内容
   - 将生成的内容粘贴到编辑器
   - 支持 Markdown 格式
   - 可以添加代码块、图片等

5. 添加话题标签（可选）
   - 点击"添加话题"
   - 选择最多 5 个相关话题
   - 增加内容曝光度

6. 保存草稿或发布
   - 点击"保存草稿"：保存到草稿箱，稍后继续编辑
   - 点击"发布回答"：直接发布（谨慎操作）

**方式 B：从草稿箱发布**

1. 访问草稿箱
   - URL: https://www.zhihu.com/drafts
   - 或点击个人头像 → 草稿箱

2. 找到对应的草稿
   - 根据时间或标题查找

3. 点击"继续编辑"

4. 检查并完善内容
   - 检查错别字
   - 补充遗漏内容
   - 添加图片或链接

5. 发布回答
   - 点击"发布"按钮
   - 确认发布

---

### 3. 发布专栏文章

1. 进入专栏写作页面
   - URL: https://zhuanlan.zhihu.com/write
   - 或点击个人头像 → 写文章

2. 输入标题
   - 在标题框输入文章标题
   - 建议简洁有力，20字以内
   - 吸引眼球但不过度标题党

3. 输入正文
   - 将生成的内容粘贴到正文编辑器
   - 支持 Markdown 格式
   - 可以添加小标题、引用、列表等

4. 添加封面图（可选但推荐）
   - 点击"添加封面图"
   - 上传图片（建议尺寸 1068x600）
   - 裁剪调整

5. 设置发布选项
   - 选择文章类型（原创/转载）
   - 如果是转载，需要注明来源
   - 设置是否允许转载

6. 保存草稿或发布
   - 点击"保存草稿"：保存到草稿箱
   - 点击"发布"：直接发布

---

### 4. 发布想法（短动态）

1. 进入想法页面
   - URL: https://www.zhihu.com/signals
   - 或点击首页顶部"想法"

2. 输入内容
   - 在输入框输入短动态
   - 最多 3000 字
   - 可以添加图片

3. 发布
   - 点击"发布"按钮

---

## 平台限制

### 回答
- **最少字数**: 300 字
- **最多字数**: 30,000 字
- **话题标签**: 最多 5 个
- **格式**: 支持 Markdown、富文本

### 专栏文章
- **标题**: 1-100 字
- **最少字数**: 无严格要求（建议 1000 字以上）
- **最多字数**: 100,000 字
- **封面图**: 建议尺寸 1068x600
- **格式**: 支持 Markdown、富文本

### 想法
- **最多字数**: 3000 字
- **图片**: 最多 9 张
- **格式**: 纯文本

---

## 注意事项

### 内容质量
- 确保内容原创或注明来源
- 避免抄袭和洗稿
- 检查错别字和语法错误
- 确保逻辑清晰、结构完整

### 发布时机
- **工作日**: 9:00-10:00, 12:00-13:00, 18:00-22:00
- **周末**: 10:00-11:00, 14:00-16:00, 20:00-23:00
- 避开深夜和凌晨发布

### 互动技巧
- 发布后及时回复评论
- 感谢点赞和关注
- 参与相关讨论
- 建立专业形象

### 常见问题

**Q: 回答保存后找不到？**
- A: 检查草稿箱：https://www.zhihu.com/drafts

**Q: 回答字数不足 300 字？**
- A: 补充更多细节、案例、分析，确保内容充实

**Q: 专栏文章发布后没有曝光？**
- A: 添加相关话题标签，分享到想法，邀请互动

**Q: 如何删除已发布的内容？**
- A: 进入内容页面 → 更多 → 删除（谨慎操作，删除后无法恢复）
