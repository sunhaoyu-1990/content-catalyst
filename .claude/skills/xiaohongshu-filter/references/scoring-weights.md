# 小红书评分权重

## 评分维度

| 维度 | 权重 | 说明 |
|------|------|------|
| 热度 | 5 | 爆款潜力和讨论热度 |
| 种草价值 | 3 | 实用性和种草能力 |
| 争议性 | 2 | 讨论价值和互动潜力 |
| 相关性 | 0 | 不强制相关（小红书内容宽泛） |

## 评分标准

### 热度 (Trending: 0-5)

**5分 - 爆款话题**
- 当前小红书热门话题
- 大量讨论和分享
- 上榜、推荐或热门标签
- 示例：刚发布的产品、季节性内容

**4分 - 上升期话题**
- 近期热门，关注度快速上升
- 讨论量显著增长
- 有成为爆款的趋势
- 示例：新兴趋势、新发布功能

**3分 - 稳定话题**
- 稳定话题，持续有人讨论
- 常青话题，经典内容
- 示例：护肤基础、穿搭技巧

**2分 - 小众话题**
- 小众领域，关注度有限
- 特定人群感兴趣
- 示例：小众爱好、细分领域

**1分 - 过时话题**
- 过时话题，几乎无人讨论
- 季节性内容，时效已过
- 示例：过时产品、已淘汰技术

**0分 - 冷门话题**
- 完全冷门，无人关注
- 无讨论价值
- 示例：无关话题

### 种草价值 (Seeding Value: 0-3)

**3分 - 高种草价值**
- 实用性强，可直接指导行动
- 产品/服务推荐价值高
- 可以立即使用或购买
- 示例：工具推荐、购物指南

**2分 - 中等种草价值**
- 有种草潜力，提供有价值信息
- 需要进一步了解
- 可以作为参考
- 示例：产品介绍、概念解析

**1分 - 低种草价值**
- 一般信息，了解即可
- 种草潜力有限
- 作为背景知识
- 示例：行业新闻、趋势分析

**0分 - 无种草价值**
- 无实质内容
- 缺乏价值
- 示例：无关广告、纯宣传

### 争议性 (Controversy: 0-2)

**2分 - 明显争议**
- 明显争议，多方观点对立
- 可引发讨论和辩论
- 有话题度
- 示例：产品缺陷、使用争议

**1分 - 轻微争议**
- 存在不同看法，可引发讨论
- 有一定话题空间
- 示例：使用感受差异、效果争议

**0分 - 无争议**
- 共识性话题，难以引发讨论
- 观点一致
- 示例：通用常识、公认标准

### 相关性 (Relevance: 0)

**0分 - 不强制相关**
- 小红书内容类型多样
- 不强制与账号定位相关
- 鼓励多样化内容
- 示例：生活方式内容可以与美妆不相关

## 入选阈值

**≥7 分**进入创作池

## 评分组合示例

### 高分组合 (9-10分)

热度高 + 种草价值高 + 有争议性

**示例**：
- 热度: 5/5
- 种草价值: 3/3
- 争议性: 1/2
- 相关性: 0/0
- 总分: 9/10 ✓ 入选

### 中高分组合 (7-8分)

热度高 + 种草价值高

**示例**：
- 热度: 5/5
- 种草价值: 3/3
- 争议性: 0/2
- 相关性: 0/0
- 总分: 8/10 ✓ 入选

### 及格组合 (7分)

热度中 + 种草价值高

**示例**：
- 热度: 3/5
- 种草价值: 3/3
- 争议性: 1/2
- 相关性: 0/0
- 总分: 7/10 ✓ 入选

## 不同内容类型的评分侧重

### 种草笔记
- **侧重**: 热度 (5分) + 种草价值 (3分)
- **最低要求**: 热度 ≥3分, 种草价值 ≥2分

### 测评分享
- **侧重**: 种草价值 (3分) + 真实性
- **最低要求**: 种草价值 ≥2分, 有真实体验

### 生活方式
- **侧重**: 热度 (5分) + 共鸣度
- **最低要求**: 热度 ≥3分, 能引发共鸣

### 美妆教程
- **侧重**: 种草价值 (3分) + 实用性
- **最低要求**: 种草价值 ≥2分, 步骤清晰

### 穿搭灵感
- **侧重**: 热度 (5分) + 视觉效果
- **最低要求**: 热度 ≥3分, 有视觉参考
