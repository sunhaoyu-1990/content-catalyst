# Filter Base Module

**共享模块**：10 分制评分系统核心逻辑

## 模块说明

本模块定义了素材评分筛选的通用 10 分制评分系统。各平台 filter skill 应继承此模块，并定制平台特定的评分权重。

## 评分系统（满分 10 分）

| 评分维度 | 默认权重 | 说明 |
|---------|---------|------|
| **热度/趋势** | 4 分 | 当前热度和趋势动量 |
| **争议性** | 2 分 | 讨论潜力和辩论价值 |
| **高价值** | 3 分 | 信息密度和可操作洞察 |
| **账号定位相关** | 1 分 | 与账号定位的匹配度 |

**阈值**：≥7 分进入创作池

## 评分标准

### 1. 热度/趋势 (Trending Score: 0-4)

```
4分: 当前热门话题，大量讨论
3分: 近期热点，关注度上升
2分: 稳定话题，持续有人讨论
1分: 小众话题，关注度有限
0分: 过时话题，几乎无人讨论
```

### 2. 争议性 (Controversy Score: 0-2)

```
2分: 明显争议，多方观点对立
1分: 存在不同看法，可引发讨论
0分: 共识性话题，难以引发讨论
```

### 3. 高价值 (Value Score: 0-3)

```
3分: 硬核干货，可直接指导行动
2分: 有价值信息，提供新视角
1分: 一般信息，了解即可
0分: 低价值，无实质内容
```

### 4. 账号定位相关 (Relevance Score: 0-1)

```
1分: 与账号定位高度相关
0分: 与账号定位关联较弱
```

## 输入格式

接受来自：

1. **collect 输出** - 结构化素材报告
2. **手动列表** - 用户提供的话题/URL
3. **原始文本** - 非结构化内容待评估
4. **资料分析结果** - 本地资料分析报告

## 评分流程

```
For each material/topic:

1. 读取用户画像 references/user-profile.md
2. 获取账号定位 domains 和相关度权重
3. 根据平台评分标准对每个维度打分
4. 计算总分 = 各维度分数之和
5. 分类:
   - ≥7分 → 入选创作池
   - 5-6分 → 待定
   - <5分 → 淘汰
```

## 平台定制接口

### 评分权重

各平台在 `references/scoring-weights.md` 中定义：

```markdown
# {Platform} 评分权重

scoring:
  trending: 4      # 热度权重
  controversy: 2   # 争议性权重
  value: 3         # 高价值权重
  relevance: 1     # 相关性权重
  threshold: 7     # 入选阈值
```

### 平台特定评分标准

各平台可根据特性调整评分标准：

**知乎示例**：
| 评分维度 | 权重 | 说明 |
|---------|------|------|
| 专业性 | 4 分 | 内容专业深度 |
| 可信度 | 3 分 | 来源可信程度 |
| 热度 | 2 分 | 讨论热度 |
| 相关性 | 1 分 | 与领域相关性 |

**小红书示例**：
| 评分维度 | 权重 | 说明 |
|---------|------|------|
| 热度 | 5 分 | 爆款潜力 |
| 种草价值 | 3 分 | 可种草程度 |
| 争议性 | 2 分 | 讨论价值 |
| 相关性 | 0 分 | 不强制相关 |

**领英示例**：
| 评分维度 | 权重 | 说明 |
|---------|------|------|
| 商业价值 | 4 分 | B2B 价值 |
| 专业性 | 3 分 | 内容专业度 |
| 热度 | 2 分 | 行业趋势 |
| 相关性 | 1 分 | 职业相关性 |

### 推荐内容类型映射

根据素材特点推荐平台特定内容类型：

| 素材特点 | 知乎 | 领英 | 小红书 |

| 技术性强 | 技术解析 | 行业评论 | - |

| ... | ... | ... | ... |

## 使用方式

**平台 skill 引用方式**：

```markdown
# {platform}-filter/SKILL.md

---

---

### 评分权重
{platform}_scoring:
  dimension1: weight1
  dimension2: weight2
  ...

### 评分标准
- 平台特定评分标准说明

### 配置文件
- scoring-weights.md: {platform} 评分权重配置
```

## 执行步骤

1. 加载素材（来自 collect 或用户输入）
2. 读取用户画像获取相关性判断依据
3. 对每个素材按 4 个维度评分
4. 计算总分并排序
5. 分类：≥7（入选）、5-6（待定）、<5（淘汰）
6. 为高分类别生成创作建议
7. 输出报告和下一步提示

## 示例

### 输入

```
素材1: Claude 4.5 Opus发布
素材2: AI编程助手对比评测
素材3: OpenAI最新裁员新闻
```

### 评分

```
Claude 4.5 Opus发布:
- 热度: 4/4 (刚发布，热门话题)
- 争议性: 1/2 (性能vs价格讨论)
- 高价值: 3/3 (新能力详解)
- 相关性: 1/1 (AI/科技相关)
- 总分: 9/10 ✓ 入选

AI编程助手对比评测:
- 热度: 2/4 (持续话题)
- 争议性: 2/2 (Cursor vs Copilot争论)
- 高价值: 3/3 (实用对比)
- 相关性: 1/1 (科技相关)
- 总分: 8/10 ✓ 入选

OpenAI最新裁员新闻:
- 热度: 3/4 (近期热点)
- 争议性: 1/2 (有讨论)
- 高价值: 1/3 (信息价值有限)
- 相关性: 0/1 (非核心领域)
- 总分: 5/10 × 待定
```

## 自定义

用户可在 user-profile.md 中自定义权重：

```yaml
scoring:
  trending: 4      # 热度权重
  controversy: 2   # 争议性权重
  value: 3         # 高价值权重
  relevance: 1     # 相关性权重
  threshold: 7     # 入选阈值
```
