# 本地资料存放目录

此目录用于存放您提供的本地资料，供内容创作时分析和整合。

## 子目录说明

### reports/
存放 PDF 格式的报告、研究论文、技术文档等。

**支持的文件类型**：
- PDF 文档 (.pdf)
- 扫描文档（OCR 可识别）

### notes/
存放 Markdown 格式的笔记、学习笔记、读书笔记等。

**支持的文件类型**：
- Markdown 文件 (.md)
- 文本文件 (.txt)

### articles/
存放文章、博客、教程等文本资料。

**支持的文件类型**：
- 纯文本文件 (.txt)
- Markdown 文件 (.md)
- 富文本（需转换为纯文本或 Markdown）

## 使用方式

1. 将本地资料复制到对应的子目录
2. 运行 `/{platform}-create`
3. 系统会提示是否需要分析这些资料
4. 选择"是"后，系统会分析并提取关键信息
5. 分析结果会自动整合到内容创作中

## 注意事项

- 请确保文件命名清晰，便于识别
- 建议按主题或项目组织文件
- 大文件（>10MB）可能需要较长的分析时间
- 敏感信息请自行脱敏处理
