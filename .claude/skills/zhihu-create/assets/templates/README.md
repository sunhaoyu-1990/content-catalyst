# 参考内容模板

此目录用于存放您认为优质的知乎内容作为参考模板。

## 子目录说明

### 专业回答/
存放优质的专业回答示例。

**用途**：学习专业回答的结构、风格和表达方式。

**如何使用**：
1. 将您认为优秀的专业回答复制到此处（Markdown 格式）
2. 运行 `/{platform}-create` 时会自动参考这些示例的风格
3. 建议至少准备 3-5 个不同领域的示例

### 专栏文章/
存放优质的专栏文章示例。

**用途**：学习专栏文章的结构、深度分析和完整表达。

**如何使用**：
1. 将您认为优秀的专栏文章复制到此处
2. 系统会参考这些示例的文章结构和深度
3. 建议准备不同长度的示例（短篇、中篇、长篇）

### 经验分享/
存放优质的经验分享示例。

**用途**：学习经验分享的实战性和真实性。

**如何使用**：
1. 将有价值的经验分享文章复制到此处
2. 系统会学习这些示例的叙事方式
3. 建议准备不同领域的经验示例

### 学术讨论/
存放优质的学术讨论示例。

**用途**：学习学术讨论的严谨性和论证方式。

**如何使用**：
1. 将高质量的学术讨论复制到此处
2. 系统会参考这些示例的论证逻辑
3. 建议准备有引用和论证的示例

### 观点评论/
存放优质的观点评论示例。

**用途**：学习观点评论的态度表达和逻辑论证。

**如何使用**：
1. 将有深度的观点评论复制到此处
2. 系统会学习这些示例的观点表达方式
3. 建议准备不同立场的示例

## 文件命名建议

建议使用清晰的文件名格式：

```
{领域}_{主题}_{作者/来源}.md

示例：
- AI_Claude4.5评测_张三.md
- 前端_工程化实践_李四.md
- 产品_需求分析_知乎高赞.md
```

## 注意事项

- 请遵守版权，仅用于个人学习和参考
- 建议定期更新和优化模板库
- 质量优先于数量
- 可以手动编辑模板文件添加注释说明
