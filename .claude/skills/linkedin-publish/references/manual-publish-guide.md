# 领英手动发布指南

## 发布方式

### 方式 1: 使用领英网站发布文章

#### 步骤 1: 登录领英

1. 访问 [领英](https://www.linkedin.com)
2. 使用账号登录
3. 点击首页的 "Write an article" 或访问 `/pulse/write`

#### 步骤 2: 创建文章

**标题** (Headline):
```
72% 的企业已开始 AI 转型，你的公司准备好了吗？
```

**封面图** (Cover Image):
- 推荐尺寸: 1920 x 1080 像素 (16:9)
- 格式: JPG, PNG
- 大小: 不超过 5MB

**正文** (Body):
```
根据 McKinsey 2025 年最新报告...

[正文内容...]

你的公司如何应对 AI 转型？欢迎在评论区分享。
```

#### 步骤 3: 格式化内容

- **标题**: 使用 H1, H2, H3 标题
- **列表**: 使用项目符号或编号
- **引用**: 使用引用格式突出重点
- **媒体**: 插入图片、视频或文档

#### 步骤 4: 预览和保存

1. 点击 "Preview" 预览效果
2. 检查内容和格式
3. 点击 "Save as draft" 保存草稿
4. 或点击 "Publish" 直接发布（谨慎）

### 方式 2: 发布动态（Post）

#### 步骤 1: 登录领英

1. 访问 [领英](https://www.linkedin.com)
2. 点击首页的 "Start a post"

#### 步骤 2: 创建动态

**正文** (100-1300 字):
```
根据 McKinsey 2025 年最新报告，72% 的企业已经开始 AI 转型...

[正文内容...]

你的公司如何应对 AI 转型？欢迎在评论区分享。
```

**话题标签** (3-5 个):
```
#AI #DigitalTransformation #BusinessStrategy
```

**媒体** (可选):
- **图片**: 点击 "Image" 上传 1-9 张图片
- **文档**: 点击 "Document" 上传 PDF/PPT
- **视频**: 点击 "Video" 上传视频文件

#### 步骤 3: 发布

1. 点击 "Save as draft" 保存草稿
2. 或点击 "Post" 直接发布

### 方式 3: 使用剪贴板工具

当 Playwright 自动化不可用时，使用剪贴板工具手动复制内容。

#### 步骤 1: 使用剪贴板工具

在项目目录运行：

```bash
cd .claude/skills/linkedin-publish/scripts

# Windows
python copy_to_clipboard.py text "你的内容"

# macOS/Linux
python3 copy_to_clipboard.py text "你的内容"
```

#### 步骤 2: 粘贴到领英

1. 访问 https://www.linkedin.com
2. 粘贴内容到发布框
3. 添加话题标签
4. 添加媒体（可选）
5. 点击 "Post"

## 内容规范

### 文章规范

- **标题**: 简洁专业，吸引目标受众
- **长度**: 100-3000 字（推荐 1500-2500 字）
- **结构**: 使用标题、副标题、列表
- **引用**: 注明数据来源
- **互动**: 结尾提出问题

**示例**:
```markdown
# 72% 的企业已开始 AI 转型，你的公司准备好了吗？

## 背景
根据 McKinsey 2025 年最新报告...

## 关键发现
### 发现 1: AI 采用率快速提升
...

## 行动建议
...

你的公司如何应对 AI 转型？欢迎在评论区分享。
```

### 动态规范

- **长度**: 100-1300 字（推荐 300-800 字）
- **结构**: 段落清晰，重点突出
- **标签**: 3-5 个话题标签
- **互动**: 结尾提问

**示例**:
```markdown
根据 McKinsey 2025 年最新报告，72% 的企业已经开始 AI 转型。

关键发现：
1. AI 采用率同比增长 40%
2. 平均 ROI 达到 3.5x
3. 领导层支持是成功关键

你的公司如何应对 AI 转型？欢迎在评论区分享。

#AI #DigitalTransformation #BusinessStrategy
```

### 话题标签规范

- **数量**: 3-5 个（推荐）
- **组合**: 热门话题 + 垂直领域
- **位置**: 放在正文结尾

**标签组合示例**:
```
#AI (热门)
#DigitalTransformation (垂直)
#BusinessStrategy (垂直)
#Leadership (相关)
```

### 媒体规范

**图片**:
- 数量: 1-9 张
- 比例: 1.91:1 (横图) 或 4:5 (竖图)
- 格式: JPG, PNG
- 大小: ≤ 5MB

**文档**:
- 格式: PDF, PPT
- 大小: ≤ 100MB
- 页数: ≤ 300 页

**视频**:
- 时长: ≤ 10 分钟
- 格式: MP4, MOV, AVI
- 大小: ≤ 5GB
- 分辨率: ≥ 720p

## 发布后检查

### 检查清单

发布后 24 小时内检查：

- [ ] 内容正常显示
- [ ] 链接有效
- [ ] 话题标签生效
- [ ] 数据统计正常（浏览、互动）
- [ ] 评论回复及时

### 数据优化

根据发布后数据优化：

- **浏览量低**: 优化标题和封面
- **互动率低**: 优化结尾引导
- **分享量低**: 增加价值点
- **评论量少**: 增加话题讨论点

## 常见问题

### Q1: 发布失败怎么办？

**A**: 检查以下几点：
1. 文章字数是否在 100-3000 字
2. 动态字数是否在 100-1300 字
3. 媒体格式和大小是否符合要求
4. 网络连接是否正常

### Q2: 如何提高曝光？

**A**: 优化以下几点：
1. 使用热门话题标签
2. 发布时间（推荐工作日 9-11 点，14-16 点）
3. 封面图质量
4. 标题吸引力
5. 互动引导

### Q3: 草稿箱在哪里？

**A**:
- 网站: 点击首页头像 → "Posts & Activity" → "Drafts"
- 或直接访问: https://www.linkedin.com/feed/drafts/

### Q4: 如何编辑已发布内容？

**A**:
1. 找到已发布的内容
2. 点击 "..." 更多选项
3. 选择 "Edit post"
4. 修改后保存

### Q5: 如何 @ 提及他人？

**A**:
1. 在正文中输入 @
2. 输入对方姓名或公司名
3. 选择正确的建议
4. 完成提及
