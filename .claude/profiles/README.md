## 📖 各Profile说明

### 1. content-creator-common.md

**定位**: 通用创作基础规范

**核心内容**:
- 创作核心原则（5条）
- 输出默认准则
- 创作流程规范
- 错误预防
- 图片使用规范

**适用范围**: 所有平台、所有类型的内容创作

**何时激活**:
- 使用任何内容创作skill时自动激活
- 作为平台特定Profile的基础

---

### 2. zhihu-creator.md

**定位**: 知乎专业深度内容

**核心特点**:
- 专业、严谨、深度
- 目标受众：技术同行、学习者
- 文章长度：3000-8000字
- 评分权重：专业性(4)+可信度(3)+热度(2)+相关性(1)

**适用场景**:
- 技术教程
- 经验分享
- 深度分析
- 工具评测

**关键要求**:
- 数据可验证
- 代码可运行
- 逻辑严密
- 深度足够

## 🔧 如何使用Profiles

### 方式1: 自动激活（推荐）

当使用内容创作skills时，相关Profile会自动激活：

```bash
# 知乎内容创作 - 自动激活 zhihu-creator.md
/zhihu-create "技术工具深度评测"

# 小红书内容创作 - 自动激活 xiaohongshu-creator.md
/xiaohongshu-create "AI写作工具推荐"

# 领英内容创作 - 自动激活 linkedin-creator.md
/linkedin-create "工具如何放大团队能力"

# X内容创作 - 自动激活 x-twitter-creator.md
/x-create "性能优化技巧"
```

### 方式2: 手动引用

在对话中明确指定Profile：

```
请使用zhihu-creator profile创作一篇关于Docker的文章
请参考xiaohongshu-creator的风格写一篇种草笔记
```

### 方式3: 组合使用

同时参考多个Profile：

```
请结合content-creator-common和zhihu-creator的要求
创作一篇专业的技术文章
```

## ⚙️ Profile扩展

### 如何创建新的Profile

如果需要为其他平台或场景创建Profile：

1. **继承通用规范**: 基于content-creator-common.md
2. **定义平台特性**: 平台特点、用户画像、评分权重
3. **制定创作规范**: 内容类型、结构、风格
4. **提供示例**: 优秀案例分析
5. **质量检查**: 发布前检查清单
