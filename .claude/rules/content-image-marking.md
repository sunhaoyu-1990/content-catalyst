# 图片标记规则

**版本**: v1.0
**触发条件**: 文章通过创作后审查，准备添加图片标记

---

## 规则目的

确保所有产出的文章都包含符合规范的图片标记，便于后续配图制作。

## 触发时机

**当检测到以下情况时，自动触发本规则**：
- `content-post-checklist.md` 审查通过
- 文章内容长度 > 2000 字
- 尚未添加图片标记

## Profile规范加载

**添加图片标记前首先加载相关Profile规范**：

### Step 1: 确定平台
- 从文件路径识别平台：`{platform}` (zhihu, xiaohongshu, linkedin, x-twitter)

### Step 2: 加载Profile规范
```
加载基础规范：
  Read profiles/content-creator-common.md

加载平台特定规范：
  如果是 zhihu → Read profiles/zhihu-creator.md
  如果是 xiaohongshu → Read profiles/xiaohongshu-creator.md
  如果是 linkedin → Read profiles/linkedin-creator.md
  如果是 x-twitter → Read profiles/x-twitter-creator.md
```

### Step 3: 应用Profile图片规范
添加图片标记时必须符合：
- ✅ Profile的图片数量要求
- ✅ Profile的图片必备类型
- ✅ Profile的图片风格要求
- ✅ Profile的宽高比规范

## 标记标准格式

每个图片标记必须包含4层信息：

```markdown
> [📷 图片X - 名称]
> **描述**：画面的中文描述（50-150字）
> **位置**：具体位置说明
> **Prompt**：AI绘画提示词
```

## Prompt 必须包含元素

**完整的Prompt必须包含以下5个元素**：

1. **场景描述**（主体 + 动作 + 环境 + 情绪）
2. **中文文字**（图片上需要显示的文字）
3. **宽高比**（`--ar X:Y`）
4. **风格**（`--style xxx`）
5. **版本**（`--v 6`）

**示例**：
```
Prompt: A professional programmer sitting at a modern desk with multiple monitors,
the screens show colorful flame graphs and performance data visualization,
bold white Chinese text title "程序员必备的性能分析工具链" at top,
--ar 16:9 --style cinematic-tech --v 6
```

## 必备图片类型

每篇文章应包含以下类型的图片：

1. **封面图**（必需）：吸引眼球的视觉焦点
2. **流程图**：展示步骤或流程
3. **对比图**：前后对比、优劣对比
4. **数据图表**：数据可视化
5. **代码截图**：技术文章必备
6. **效果截图**：真实效果展示
7. **总结卡片**：要点提炼

## 图片插入原则

### 位置原则
- 封面图：文章开头
- 流程图：相关方法/步骤介绍之后
- 对比图：对比内容之后
- 数据图：数据说明之后
- 总结图：章节末尾或全文总结

### 密度原则
- 每500-800字应有一张图片
- 长段落（>10行）应有配图
- 关键概念应有可视化说明

### 风格一致性
- 同一篇文章的图片风格保持一致
- 色彩方案协调
- 设计语言统一

## 质量检查清单

添加图片标记后，检查以下项目：

- [ ] 图片编号连续（图片1、图片2...）
- [ ] 每个标记包含4层信息
- [ ] Prompt包含5个必需元素
- [ ] 图片数量符合平台指南
- [ ] 图片位置合理
- [ ] 风格描述清晰
- [ ] 宽高比适合平台

## 常见问题

| 问题 | 解决方法 |
|------|---------|
| Prompt缺少中文文字 | 添加 `Chinese text "具体内容"` |
| 宽高比不合适 | 根据平台调整（知乎16:9，小红书4:3） |
| 风格描述模糊 | 明确风格类型（`--style cinematic-tech`） |
| 图片过多 | 合并相似图片，删除冗余 |
| 图片位置不当 | 调整到更相关的位置 |

## 完成标志

**当以下条件满足时，图片标记完成**：
- [ ] 图片数量符合推荐范围
- [ ] 所有图片标记格式完整
- [ ] Prompt包含所有必需元素
- [ ] 质量检查全部通过

## 自动触发下一阶段

**图片标记完成后**：
- 文章可以进入发布准备阶段（03_publish）
- 使用 `{platform}-publish` skill 生成发布指南

---

**重要说明**：

2. 图片标记必须在审查通过后进行
