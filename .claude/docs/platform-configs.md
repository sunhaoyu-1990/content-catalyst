# 平台详细配置

**用途**: 本文档详细说明各平台的内容类型、评分权重和风格特点。

---

## 知乎 (Zhihu)

### 内容类型

| 类型 | 描述 | 适用场景 |
|------|------|---------|
| 专业回答 | 严肃、专业、有深度的回答 | 学术问题、技术讨论 |
| 专栏文章 | 长篇深度文章 | 系统知识分享 |
| 经验分享 | 个人经历、实战经验 | 职场、学习经历 |
| 学术讨论 | 引用论文、数据支持 | 研究型话题 |
| 观点评论 | 分析评论、独到见解 | 热点事件分析 |

### 评分权重

```
专业性 (4) + 可信度 (3) + 热度 (2) + 相关性 (1) = 10 分
```

**权重解释**：
- **专业性 (4)**: 最重要的因素。内容是否有深度、专业性
- **可信度 (3)**: 引用是否可靠、论证是否严密
- **热度 (2)**: 讨论度、关注度
- **相关性 (1)**: 与目标主题的相关程度

**入选阈值**: ≥ 7 分

### 风格特点

- **语言**: 专业严肃，逻辑严密
- **结构**: 数据驱动，引用权威
- **长度**: 中长篇（1000-3000字）
- **格式**: 支持 Markdown，适合技术内容

### 典型示例

**好回答**：
- 引用论文、数据支持
- 逻辑清晰，层层递进
- 有个人独到见解

**避免**：
- 纯主观感受
- 缺乏论据的观点
- 过于口语化

## 小红书 (Xiaohongshu)

### 内容类型

| 类型 | 描述 | 适用场景 |
|------|------|---------|
| 种草笔记 | 产品推荐、使用体验 | 美妆、生活用品 |
| 测评分享 | 详细测评、对比分析 | 数码、家居 |
| 生活方式 | 日常分享、vlog文字版 | 旅行、美食、穿搭 |
| 美妆教程 | 化妆步骤、技巧 | 化妆、护肤 |
| 穿搭灵感 | 搭配建议、单品推荐 | 服装、配饰 |

### 评分权重

```
热度 (5) + 种草价值 (3) + 争议性 (2) + 相关性 (0) = 10 分
```

**权重解释**：
- **热度 (5)**: 最重要。是否受欢迎、有传播潜力
- **种草价值 (3)**: 是否有实用价值、能激发购买欲
- **争议性 (2)**: 是否能引发讨论
- **相关性 (0)**: 不作为评分因素，但在筛选时考虑

**入选阈值**: ≥ 7 分

### 风格特点

- **语言**: 亲和力强，像朋友推荐
- **结构**: 图文并茂，emoji 丰富
- **长度**: 中短篇（500-1500字）
- **格式**: 支持图片、视频，视觉化表达

### 典型示例

**好笔记**：
- 真实使用感受
- 清晰的产品图片
- 详细的优缺点分析
- 适合新手的指导

**避免**：
- 纯广告
- 缺乏细节
- 过于正式

## 领英 (LinkedIn)

### 内容类型

| 类型 | 描述 | 适用场景 |
|------|------|---------|
| 行业洞察 | 趋势分析、行业观察 | 专业领域分享 |
| 专业分享 | 知识经验、技能分享 | 技能展示 |
| 案例研究 | 成功案例分析 | 商业案例 |
| 职场发展 | 职场建议、成长经历 | 职业规划 |
| 观点文章 | 专业观点、思考 | 行业讨论 |

### 评分权重

```
商业价值 (4) + 专业性 (3) + 热度 (2) + 相关性 (1) = 10 分
```

**权重解释**：
- **商业价值 (4)**: 最重要。是否有实用商业价值
- **专业性 (3)**: 内容的专业深度
- **热度 (2)**: 行业关注度和讨论度
- **相关性 (1)**: 与目标受众的相关性

**入选阈值**: ≥ 7 分

### 风格特点

- **语言**: 数据驱动，职业化
- **结构**: 商业导向，价值明确
- **长度**: 中篇（800-2000字）
- **格式**: 支持专业格式，适合商业内容

### 典型示例

**好内容**：
- 有数据支持的观点
- 清晰的商业洞察
- 可行动的建议
- 专业但不晦涩

**避免**：
- 纯个人生活
- 缺乏专业价值
- 过于随意

## X (Twitter)

### 内容类型

| 类型 | 描述 | 字数限制 |
|------|------|---------|
| 短推文 | 单条推文，简洁有力 | ≤280 字符 |
| 线程 (Thread) | 多条推文串联，深度内容 | 每条 ≤280 字符 |
| 回复 (Reply) | 回复他人，参与讨论 | ≤280 字符 |

### 评分权重

```
影响力 (4) + 相关性 (3) + 时效性 (2) + 传播度 (1) = 10 分
```

**权重解释**：
- **影响力 (4)**: 最重要。是否能引发共鸣、获得认同
- **相关性 (3)**: 与目标话题的相关程度
- **时效性 (2)**: 是否紧跟热点、实时性强
- **传播度 (1)**: 是否易于转发、传播

**入选阈值**: ≥ 7 分

### 风格特点

- **语言**: 简洁有力，一针见血
- **结构**: 快速切入，重点突出
- **长度**: 极短（≤280 字符）
- **格式**: 支持话题标签、@提及

### 典型示例

**好推文**：
- 观点鲜明，立场明确
- 有数据或引用支持
- 使用合适的话题标签
- 易于转发和讨论

**避免**：
- 空洞无物
- 过于复杂
- 缺乏个性

## 内容适配策略

### 同一主题，不同平台

**主题**: "AI写作工具推荐"

**知乎版本**：
- 标题：《AI写作工具深度评测：从原理到实践》
- 风格：专业、技术分析、对比评测
- 长度：2500 字
- 内容：技术原理、工具对比、使用场景

**小红书版本**：
- 标题：《超好用！5款AI写作工具推荐✨》
- 风格：亲切、emoji 丰富、图文并茂
- 长度：800 字
- 内容：工具介绍、使用体验、推荐理由

**领英版本**：
- 标题：《AI写作工具如何提升职场效率》
- 风格：商业导向、数据驱动
- 长度：1200 字
- 内容：效率提升、商业价值、行业趋势

**X版本**：
- 内容：3条线程
  1. 抛出观点："AI写作工具能让效率提升10倍，但这5款最好用"
  2. 列举工具：简短介绍每个工具的核心优势
  3. 个人观点：分享使用体验和建议
- 话题标签：#AI #写作工具 #效率
